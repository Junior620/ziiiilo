# Polices des images de partage

Fichiers TTF statiques des polices du site, téléchargés depuis Google Fonts et utilisés uniquement par `src/lib/og/render.tsx` : Satori, le moteur de `next/og`, ne lit pas le WOFF2 servi par `next/font`.

- `Sora-SemiBold.ttf` : titres
- `Inter-Medium.ttf`, `Inter-SemiBold.ttf` : textes
- `JetBrainsMono-Medium.ttf` : surtitre « terminal » et domaine

Les trois familles sont sous licence SIL Open Font License 1.1, qui autorise leur intégration et leur redistribution avec le site.
